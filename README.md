# 2026 CUMCM A 题：药材烘干过程建模

本仓库汇集 2026 年全国大学生数学建模竞赛 A 题“药材烘干过程”的完整建模成果，包括数据处理、数值求解、结果复现、图件和论文终稿。

## 项目内容

- `Q1`–`Q4`：四个问题的建模说明、数据分析和求解结果。
- `problem A`：题目附件及中间数据。
- `results`：数值计算输出和汇总数据。
- `figures`：论文使用的图件及其可复现绘图脚本。
- `完整论文-LaTeX`：论文 LaTeX 源文件。
- `完整论文.pdf`、`完整论文-仅正文.pdf`：论文成稿。
- `支撑材料`：提交所需的复现材料、脚本和结果文件。

## 核心方法

项目以圆柱形药材的热风干燥为对象，建立一维轴对称热传导—水分扩散模型，并按问题逐步考虑时变边界、温湿相关物性和尺寸收缩。数值计算采用径向有限体积离散、隐式时间推进和 Picard 迭代；烘干终点以全域含水率阈值判定。

## 复现说明

1. 安装项目所需的 Python 依赖（如 `numpy`、`pandas`、`matplotlib`）。
2. 从各问题目录中的求解与绘图脚本开始运行；根目录的 `使用指南.md` 和 `repro_manifest.py` 提供补充说明。
3. 查看 `results` 与 `figures`，或直接打开根目录论文 PDF 获取最终结果。
