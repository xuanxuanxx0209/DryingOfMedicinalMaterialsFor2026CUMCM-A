# 几何与传热传质示意图

建议放在正文“问题一的几何简化”之后。图像为程序绘制，未使用生成式图像工具；提供彩色和纯黑白两个版本。PDF 为论文插图首选，SVG 保留文字和矢量图形，PNG 为 600 DPI 预览。尺寸 180 mm × 110 mm，建议通栏排版。

## 可用图注

圆柱药材的几何简化与径向传热传质示意图。（a）药材长度为 25 cm，半径为 2 cm；在轴对称及忽略轴向梯度、端面传递的假设下，建立一维径向模型。（b）横截面放大示出升温失水工况下热量向内传递、水分向外迁移的方向。实线箭头表示热量传入，虚线箭头表示水分逸出，箭头长度不代表通量大小。侧壁边界统一以径向向外为正；轴线满足零梯度条件。

| 换热系数 | 题目附录 2：h=25 W/(m²·K)。图中保留 h，不引入新的数值。 |

| 侧壁热边界 | 与正文式 `eq:heat-surface` 相同。升温工况 T_a>T(R,t)，故向外热通量为负，箭头指向内部。初始瞬间温差可能为零，图注限定为升温失水工况。 |

| 轴线边界 | 径向对称下 ∂T/∂r=∂C/∂r=0，不是表面绝热。 |
| 模型假设 | 忽略轴向梯度及端面传递来自本文模型假设，不是题目实测结论。 |
| 适用范围 | 固定半径模型（问题 1—3）的几何说明；不声称问题 4 的半径始终为 2 cm。 |

## 使用

彩色版与黑白版内容一致。黑白版除浅灰材料填充外，文字和线条均为黑色，通过线型与箭头方向区分传递过程。图注放在论文排版中，图片内不预设图号。

运行 `绘制示意图.py` 可复现两套 PDF、SVG、PNG 和 `核对记录.json`。该记录包含题目 PDF 的 SHA256、核对参数与文字裁切检测结果。
