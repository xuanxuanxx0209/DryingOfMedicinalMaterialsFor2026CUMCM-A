# 问题三数据剖析

## 数据结构

附件一共有 241 条逐分钟记录，时间覆盖 0 至 14400 秒，温度与空气水分浓度均无缺失。9000 至 14400 秒的稳定段含 91 条记录。该时段温度均值为 50.004945 摄氏度，总体标准差为 0.154016 摄氏度；空气水分浓度均值为 0.04999374 千克每千克，总体标准差为 0.000153463 千克每千克。长期外推采用稳定段均值，不采用末条记录。

附件全段包含预热和稳定两个状态。温度与空气水分浓度的 Pearson 相关系数为 0.9833，两者共同随时间趋于平台。全段分布的偏态由预热阶段造成，不宜用全段均值代表长期边界；稳定段均值能保留平台水平并削弱单点噪声。稳定段极差分别为 0.489 摄氏度与 0.00050 千克每千克，后续边界敏感性据总体标准差构造。

## 求解结果特征

问题三关键过程表共有 3447 条记录，覆盖 0 至 206756 秒。五个指定径向位置的含水率均无缺失，范围为 0.052653 至 2.550000 千克每千克。中心含水率等于记录时刻的最大含水率；除开头少量对称性扰动定位外，最大值位置保持在中心。各位置含水率随时间单调下降，程序记录的最大反向增量仅为 3.997e-15 千克每千克，可视为浮点舍入。

五条含水率时间序列呈右偏分布，这是干燥前段高含水率占比较小所致。它们之间的 Pearson 相关系数均不低于 0.989，表明各位置共享同一干燥趋势，但表面响应更快。图件应优先展示时间轨迹、径向场和阈值交点，不用均值柱状图概括非平稳序列。

## 风险与作图约束

边界敏感性只有六个确定性工况，每个工况只有一个计算结果，不具备重复样本意义。该结果采用零基准的横向点图展示相对变化，不绘制均值柱和统计误差棒。时间步与空间网格数据也是确定性离散试验，采用点图或哑铃图，并在图内标明门槛。

最终图件不用双纵轴，不用彩虹色图，不把离散工况连成折线。连续色阶均配单位明确的色标。全部图件输出 PDF、SVG、300 DPI PNG 和灰度预览；正文优先放入阈值轨迹、指定位置轨迹与边界敏感性三张图，其余作为证据候选。
